数据 + 算力 + 算法
- 算力 ？ 
  设备处理数据、完成运算任务的计算能力（显存、cuda）。
不完全是。
- 算法 ？
  transformer架构(Google 论文)，以概率逻辑完成文本理解、生成与推理的整套计算规则。
  随机、不确定性的
也不完全是。
- 最关键的是预训练数据
  机器学习，人的学习。
  llm智能的来源
  结构清晰、分工明确的数据。

  从AI模型训练的视角（train，算力（千百亿遍），算法，数据特征，关联，神经网状），
  大模型不是背数据的，是学习、理解、验证、测试。
  数据到底怎么划分（几部分，一部分用于训练，一部分用于验证，一部分用于测试）

  书本，train 学习    80%
  作业，课后测试 验证  10%
  期中期末，高考 测试  10%

  在大模型公司，到底有哪些更聪明的数据组织方案，数据工程是非常核心的。

## 数据分类
- 训练集 train datasets
  学生用的教材 吸收知识 
- 验证集 validate datasets
  课后作业，帮助学生查漏补缺 
- 测试集 test datasets
  考试，测试学生的学习效果

  训练集目的让模型去查找数据的一个规律。
  验证集就是**频繁**地去验证我的模型训练好坏，来帮助我们去调节一些参数。
  测试集就相当于去验证我训练好的模型，它在没有看到的数据上的一个泛化能力。
