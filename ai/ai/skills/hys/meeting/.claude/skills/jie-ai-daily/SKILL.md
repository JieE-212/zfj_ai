# 杰哥每日 AI 新闻概览

搜罗近 24 小时 AI 领域重要新闻，生成中文精华摘要和精美的可视化日报 HTML 页面。让用户用最少的时间掌握最新行业动态。

## 工作流程

### 第一步：多源搜索 AI 新闻

使用 `WebSearch` 工具，分别从以下来源搜索近期的 AI 新闻：

1. **TechCrunch AI 板块**：搜索 `site:techcrunch.com AI artificial intelligence news`
2. **The Verge AI 板块**：搜索 `site:theverge.com AI artificial intelligence news`
3. **Hacker News**：搜索 `site:news.ycombinator.com AI LLM machine learning`
4. **综合搜索**：额外做一次无站点限制的搜索 `AI industry breaking news today 2025`，捕获其他来源的重要新闻

每个搜索至少获取 5-8 条结果。优先选择标题或摘要中明确涉及 AI/ML/LLM/大模型/人工智能 的条目。

### 第二步：获取文章详情

对搜索到的候选文章（去重后），使用 `WebFetch` 工具获取每篇文章的详细内容。目标：

- 提取文章的核心事实：发生了什么、涉及哪些公司/人物、技术细节、影响范围
- 识别文章的发布时间，过滤超过 48 小时的旧闻
- 每篇文章抓取后，判断其价值：是否属于 AI 行业核心动态（产品发布、融资、研究突破、政策监管、行业趋势），剔除纯八卦、软文、与 AI 无关的内容

### 第三步：智能过滤与排序

从所有候选中精选 **6-10 条**最有价值的资讯。筛选标准（按优先级）：

1. **重大产品发布/更新**：OpenAI、Google、Meta、Anthropic、Microsoft 等头部公司的新产品/功能
2. **融资与商业动态**：AI 创业公司融资、收购、上市
3. **技术突破**：新模型、新架构、重要论文、开源发布
4. **政策与监管**：各国 AI 法规、安全政策
5. **行业趋势**：AI 应用落地、人才流动、市场报告

最终按重要性从高到低排序。

### 第四步：生成中文摘要

为每条入选资讯撰写中文摘要：

- **核心要点**：50-100 字，提炼新闻的核心事实和影响
- **关键词标签**：2-4 个中文关键词，如 `大模型` `开源` `融资` `Gemini` `监管`
- **来源标注**：标明文章来源（TechCrunch / The Verge / Hacker News / 其他）

摘要写作原则：
- 用事实说话，不夸张不标题党
- 包含具体公司名、产品名、数字
- 讲清楚"发生了什么"和"为什么重要"
- 语言简洁流畅，适合快速阅读

### 第五步：生成可视化 HTML 日报

按以下规范生成 HTML 文件，保存到用户当前工作目录下的 `杰哥AI日报-YYYY-MM-DD.html`。

#### HTML 设计规范

整体风格：现代、清爽、专业。使用卡片式布局，每张卡片承载一条资讯。

**必须包含的元素：**

1. **顶部标题区**：`[杰哥AI日报]` + 日期（如 `2025-07-17`），带副标题显示资讯条数
2. **日期导航**：简洁的日期显示
3. **资讯卡片列表**：每张卡片包含：
   - 序号标签（#1, #2, ...）
   - 新闻标题（中文意译，非直译）
   - 摘要正文（50-100字）
   - 关键词标签（彩色小标签）
   - 来源标识和原文链接
   - 发布时间（如有）
4. **页脚**：数据来源说明 + 生成时间

**设计细节：**
- 使用 CSS Grid 或 Flexbox 实现卡片布局
- 响应式设计，桌面端 2 列、移动端 1 列
- 卡片带有微妙的阴影和悬停动效
- 使用适合阅读的中文字体栈
- 配色方案：深蓝主色调 + 白色卡片，标签使用柔和彩色
- 每条卡片的原文链接要可直接点击（target="_blank"）
- 页面内嵌所有 CSS，无需外部依赖

**HTML 模板参考：**

读取 `assets/template.html` 获取完整的 HTML 模板结构。基于该模板填充实际内容。如果模板文件不可用，按照以下结构生成：

```
<!DOCTYPE html> → <head> (meta, title, style) → <body> → 
  <header> (标题、日期、副标题) → 
  <main> (卡片列表) → 
  <footer> (来源说明)
```

**重要提醒：**
- 必须使用 `Write` 工具将 HTML 保存到文件
- 文件路径使用绝对路径
- 生成完 HTML 后，向用户报告文件路径和资讯概览

## 注意事项

### 时效性优先

搜索时关注最近 24-48 小时内的新闻。如果搜索 API 不支持时间过滤，则通过文章内容中的时间信息手动判断。

### 中文表达自然

标题和摘要使用地道的中文表达。英文公司名和产品名保留原名（如 OpenAI、ChatGPT），避免生硬翻译。

### 价值判断

不是所有带 "AI" 关键词的新闻都值得收录。优先选择：
- 影响面广的（头部公司、主流产品）
- 有深度的（技术突破、行业分析）
- 可操作的（开发者工具、开源项目）

跳过：
- 纯 PR 通稿
- 重复报道（同一事件选最佳来源）
- 与 AI 无关的科技新闻

### 容错处理

如果某些来源搜索失败或无法获取详情，不要中断流程——标注该来源暂无数据，继续处理其他来源。最终至少保证 3-5 条精选资讯。
