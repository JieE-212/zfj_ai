# 会议纪要生成

根据会议录音转写文字稿，生成结构化、可执行的中英双语会议纪要。

## 工作流程

### 第一步：通读与清洗

通读全文，理解会议整体脉络，然后执行清洗：

- **去除口语化冗余**：语气词（嗯、啊、那个、这个、就是说、然后呢、对吧、you know、um、uh、like、I mean）、重复表达、口吃修正
- **去除闲聊**：与会议主题无关的寒暄、私人对话
- **保留实质内容**：确保清洗后不丢失任何观点、决策、数据、人名、时间承诺

> 清洗不是改写——保留发言人的原意原话，只是去掉干扰理解的噪音。

### 第二步：结构化提取

按以下结构梳理信息。**宁缺毋滥：不确定的内容直接留空，不要编造。**

### 第三步：双语输出

按下方模板输出。中文为主，英文作为对照。如果原文为纯中文且无英文需求，可只输出中文；如果参会者包含非中文人员，英文版同样重要。

## 重要原则

### 1. 宁可留空，不要编造

文字稿中没有明确提到的信息，字段留空或写"未提及 / Not mentioned"。**绝不根据常识或上下文猜测填补**——缺失的信息可能恰好是后续需要跟进的事项。

### 2. 行动项是最重要的产出

一份会议纪要的价值，80% 在于行动项是否清晰。务必：
- 从讨论中精准识别承诺和待办
- 确认负责人和截止时间（如果原文有的话）
- 用可验证的动宾结构描述（"完成XX"、"发送XX邮件给YY"、"提交XX方案"）

### 3. 议题按逻辑划分，而非时间顺序

不要简单按发言顺序罗列内容。理解每个讨论段落的主题，把相关讨论归并到同一议题下。一个议题 = 一个可独立理解的主题。

### 4. 观点要标注发言人

观点栏必须关联到具体发言人，这既是对发言人的尊重，也便于后续追溯和问责。

### 5. 识别"伪共识"

关注以下信号：
- 有人提出建议后无人回应 → 不等于同意，标注为"待确认"
- "线下再聊" → 通常是推迟决策，需要跟踪
- 模糊的"行吧"/"可以" → 可能是勉强同意，如有保留意见也应记录

## 使用示例

### 输入（文字稿片段）

```
[00:05:23] 张总：那个，嗯，我们今天主要聊一下Q3的推广方案。就是上次说的那个预算问题还没定嘛，对吧。
[00:05:45] 李经理：对，然后呢我觉得我们可以先看一下竞品最近在做什么，他们那个抖音投放还挺猛的。
[00:06:10] 张总：嗯嗯，这个方向可以。那小王你这边能不能这周内出一个竞品分析的初稿？
[00:06:25] 小王：好的张总，我这周五之前发出来。
[00:06:40] 李经理：还有就是我们自己的小红书账号，那个数据一直在掉，得想个办法。
```

### 输出（对应部分）

```markdown
## 三、会议内容 / Meeting Discussion

### 议题一 / Topic 1：Q3 推广方案与竞品分析 / Q3 Promotion Plan & Competitor Analysis

**讨论要点 / Key Discussion Points：**

- Q3 推广方案的预算尚未确定
- 竞品近期在抖音平台的投放力度加大
- 自有小红书账号数据持续下滑

**主要观点 / Main Viewpoints：**

| 发言人 / Speaker | 观点 / Viewpoint |
|---|---|
| 张总 / Zhang | Q3 推广方案需要尽快敲定预算；赞同竞品分析方向 |
| 李经理 / Li | 建议先对竞品（特别是抖音投放）做调研；关注小红书账号数据下滑问题 |

**结论/决策 / Decision：**
- 启动竞品分析，重点关注抖音平台投放策略
```
