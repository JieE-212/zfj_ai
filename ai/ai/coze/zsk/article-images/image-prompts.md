# 文章 AI 配图生成提示词

## 图1：AI Agent 架构示意图
**对应章节**：第一部分 —— "AI Agent 究竟是什么？"
**文章位置**：AI Agent定义段落后

### Prompt（中文）
```
一幅科技感十足的 AI Agent 架构示意图，扁平化设计风格。
画面中央是一个发光的半透明大脑图标，代表大语言模型（LLM），
大脑下方连接着多个功能模块图标：扳手（工具调用）、书本（知识库检索）、
齿轮（自动化执行）、对话框（交互界面）。
整体色调为深蓝到紫色渐变，带霓虹光效，科技感强。
线条连接各个模块，形成"大脑指挥手脚"的视觉隐喻。
16:9 横版比例，干净简洁的信息图表风格。
```

### Prompt（English / Midjourney）
```
A tech-style AI Agent architecture infographic, flat design, digital illustration.
A glowing translucent brain icon at the center representing the LLM,
connected to smaller modules below: a wrench (tools), a book (knowledge base),
a gear (automation), a chat bubble (interface).
Dark blue to purple gradient background with neon blue glowing connection lines.
Clean infographic style, 16:9 aspect ratio, no text labels, minimalist.
--ar 16:9 --style digital --v 6
```

## 图2：RAG 检索增强生成流程图
**对应章节**：第二部分 —— "知识库：AI Agent的外脑"
**文章位置**：知识库本质说明段落后

### Prompt（中文）
```
RAG（检索增强生成）技术流程图，扁平化信息图风格。
从左到右展示四个步骤：
1. 用户提问（人物剪影+问号图标）
2. 知识库检索（文档图标+放大镜，蓝色高亮）
3. 相关内容提取（文档碎片飞向中心，橙色高亮）
4. LLM生成回答（发光大脑+完整回答输出，绿色高亮）
箭头连接各步骤，整体浅色背景，清新科技风格。
16:9 横版，适合技术博客配图。
```

### Prompt（English / Midjourney）
```
A RAG (Retrieval Augmented Generation) flow diagram, flat infographic style,
light background, clean tech aesthetic. Left to right flow:
1. User asking a question (silhouette with question mark)
2. Knowledge base search (document icon with magnifying glass, blue highlight)
3. Relevant context extraction (document fragments flowing to center, orange)
4. LLM generating answer (glowing brain with output text, green highlight)
Connected by clean arrows, 16:9 aspect ratio, suitable for tech blog illustration.
No text labels needed, iconographic style. --ar 16:9 --style digital --v 6
```

## 图4：Prompt 设计对比（好 vs 坏）
**对应章节**：第四部分 Step2 —— "编写 Prompt"
**文章位置**：Prompt边界规则代码块后

### Prompt（中文）
```
一张对比图，左右分栏设计。
左边标红色（"❌ 模糊 Prompt"）：显示模糊的文字块，代表不好的 Prompt，
背景带轻微红色调，整体显得混乱。
右边标绿色（"✅ 清晰 Prompt"）：显示结构清晰的文字块，
包含角色定义、能力列表、边界说明，背景带轻微绿色调，显得有序。
中间用闪电符号分隔。整体扁平设计风格，适合技术博客。
16:9 横版，对比信息图风格。
```

### Prompt（English / Midjourney）
```
A comparison infographic, split screen design, left vs right.
Left side (red tinted, labeled BAD): a blurry, messy text block
representing a poorly written prompt, chaotic visual feel.
Right side (green tinted, labeled GOOD): a clean, structured text block
with clear sections for persona, capabilities, and boundaries.
Divided by a lightning bolt icon in the center.
Clean flat design, 16:9 aspect ratio, tech blog illustration style.
--ar 16:9 --style digital --v 6
```
